# Lumine Window Films — Single Page Website

A modern, stylish one-page site for a window film business. Built with plain HTML, CSS, and JavaScript. No build steps required.

## Quick start

Open `index.html` in a browser or use a simple static server:

```bash
python3 -m http.server 8080 --directory /workspace
```

Then visit `http://localhost:8080`.

## Customize

- Brand: Update the name "Lumine" and the logo at `assets/logo.svg`.
- Colors: Edit CSS variables at the top of `styles.css`.
- Copy: Change text in `index.html` sections (hero, benefits, films, etc.).
- Images: Replace gallery URLs with your own images or host locally.
- Contact: Update phone/email in the footer and the `tel:` link in the hero.

## Structure

- `index.html` — Page structure, SEO/meta, sections
- `styles.css` — Theme, layout, components, responsive rules
- `script.js` — Mobile nav, smooth scroll, FAQ, basic form validation
- `assets/` — Logo and favicon SVGs

## Deploy

Host on any static host (GitHub Pages, Netlify, Vercel, S3). Upload the files as-is.
